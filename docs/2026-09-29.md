# 2026-09-29

## Objective

Exact replication of the original Sundial implementation.

The goal at this stage is to reproduce the released Sundial implementation exactly as the official implementation is. No architectural simplification, downscaling, or cold-start modification is being introduced at this stage.

## Replication Structure

The released Sundial implementation is preserved under:

```text
reference/
└── sundial-base-128m/
```

This directory serves as the reference implementation and will remain unchanged.

An independent replication directory was created under:

```text
src/
└── original_sundial_replication/
    ├── configuration_sundial.py
    ├── flow_loss.py
    ├── modeling_sundial.py
    └── ts_generation_mixin.py
```

## Official vs Replication

The `reference/sundial-base-128m/` directory contains the released Sundial implementation and checkpoint. It is treated as the reference and is not modified.

The `src/original_sundial_replication/` directory contains our reproduction of the released implementation.

The official implementation is executed first to establish a working baseline. The replicated implementation will then be executed and compared against this baseline before any modifications are made for cold-start forecasting.

## Official Inference Script

The script `scripts/run_official_sundial.py` was created to execute the released Sundial implementation from `reference/sundial-base-128m/` and establish the official baseline.

It was successfully executed using the local CUDA environment.

## Official Implementation Verification

The released Sundial implementation was successfully loaded from the local reference directory and executed on CUDA.

The test used:

```text
    Context length: 2880

```
