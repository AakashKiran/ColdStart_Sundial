# 2026-09-28 

## Environment Setup

A dedicated Conda environment named `sundial` was created for the replication work.

The environment uses **Python 3.10.21**, as recommended by the Sundial implementation for stable compatibility.

## Dependency Management

A `requirements.txt` file was created to explicitly specify the direct dependencies required for the project.

The file records the versions relevant to the Sundial replication:

```text
torch==2.7.1+cu126
transformers==4.40.1
```

A `requirements-lock.txt` file was also generated as a complete snapshot of the Python environment using `pip freeze`. This records all installed packages, including transitive dependencies, to provide an exact record of the environment used during replication and maximize reproducibility.

An `environment.yml` file was created to define the Conda environment, including the required Python version and `pip`.

The project therefore maintains three levels of environment information:

| File                    | Purpose                                           |
| ----------------------- | ------------------------------------------------- |
| `environment.yml`       | Defines the Conda/Python environment              |
| `requirements.txt`      | Specifies direct project dependencies             |
| `requirements-lock.txt` | Records the complete installed Python environment |
